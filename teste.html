Página 1 — Teste de limite A4

Esta página tem grade de 10mm, régua nas laterais e marcações nos quatro cantos. Ela serve para identificar se o navegador está reduzindo, cortando ou deslocando a impressão.

A borda vermelha clara representa a área crítica próxima ao corte. A linha azul tracejada representa uma área segura para colocar conteúdo.

Azul tracejado:
área segura para textos, imagens e blocos principais.
Vermelho:
região de risco, próxima das bordas do papel.
Grade:
cada quadrado equivale a aproximadamente 10mm.
Rodapé:
verifique se o número da página aparece completo.

Página 3 — Teste de altura do conteúdo

Esta página simula vários blocos de conteúdo para testar se o último bloco fica cortado ou se ainda sobra espaço antes do rodapé.

Bloco 1: texto dentro da área segura.
Bloco 2: teste de espaçamento vertical.
Bloco 3: verifique se as bordas aparecem completas.
Bloco 4: conteúdo intermediário.
Bloco 5: este bloco ajuda a testar o limite inferior.
Bloco 6: se este bloco cortar, reduza padding, fonte ou altura dos blocos.
Área próxima ao rodapé: se esta faixa sair cortada, aumente a margem inferior interna da página.

Página 4 — Página modelo para conteúdo real

Esta é uma página mais parecida com um informativo final. A ideia é testar uma combinação de título, textos, quadros e rodapé.

Resumo

Use esta estrutura como base para criar informativos em HTML que serão impressos em PDF ou enviados aos clientes.

Área segura

Todo o conteúdo principal deve ficar dentro da linha azul. Elementos decorativos podem chegar mais perto das bordas, mas não textos importantes.

Teste prático

Ao imprimir, veja se o título, os quadros, a linha azul, os cantos vermelhos e o número da página aparecem corretamente.

Anote o que saiu cortado: topo, base, esquerda, direita, fundos, rodapé ou conteúdo interno. Com isso dá para ajustar o tamanho exato.
